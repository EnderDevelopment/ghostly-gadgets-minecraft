# GhostHunting Mod

GhostHunting Mod is a Minecraft mod that adds EMF Reader and Spirit Box functionality for ghost hunting. The EMF Reader displays random levels between 2-5 and shows ORB effects, while the Spirit Box allows communication with a fake ghost using 10 predefined words.

## Install

1. Install the Fabric Loader for Minecraft version 1.20.4.
2. Download the GhostHunting mod jar file from the GitHub releases page.
3. Place the jar file in the `mods` folder of your Minecraft installation.

## Use

1. Launch Minecraft with the Fabric Loader and the GhostHunting mod installed.
2. To use the EMF Reader, right-click to display the EMF level and ORB effects.
3. To use the Spirit Box, right-click to communicate with the fake ghost.
